# AI Policy

This document will be dynamically amended whenever new LLM related problems affect the project.

We realize the metadata in this repository is simple enough that LLM generated changes will not neccessarily be of worse quality. However the project lives of people having an overview of their region, so that alone is not enough. On the positive side, that means the metadata is simple to edit by hand without programming experience as well.

Please do not:

 - Use LLMs for communication (except for machine translations).
 
   This includes chat, issues, commit descriptions etc.
 - Create commits using LLM harnesses such as Claude Code.
 
   The minimum expectation is that you review your changes before submitting them. Creating the commit yourself is the minimum proof of that.
 - Use LLMs for researching the licenses of data. We need them to be actually correct.
 - Submit changes that you do not understand.


Caveats of using LLMs in this project:

 - Visibly LLM generated changes will be reviewed with about the effort that was put into them.
 - They may be reviewed with less goodwill
